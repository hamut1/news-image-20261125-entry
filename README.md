# The World in One Day

A one-image summary of the world news of Wednesday 25 November 2026, laid out as a newspaper front page.

- Two tankers hit by mines in Hormuz
- Houthis hit Saudi refinery
- Israel kills Hamas security chief
- Russia strikes Odesa and Kyiv
- COP31 talks fail
- Solomons sign Pacific pact

Run with Node.js 22.18 or later to write the image to `out/entry.png`:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
